# CuraNexa 🩺

**Cura (care) + Nexa (connection).**

CuraNexa is a full-stack Doctor Appointment Booking System built using the MERN stack (MongoDB, Express.js, React.js, and Node.js). It simplifies healthcare access by allowing patients to discover doctors, explore their profiles, check availability, and book appointments through an intuitive interface.

The platform provides dedicated experiences for patients, doctors, and administrators, making appointment management more organized, accessible, and efficient.

### ✨ Key Features
- 👤 User authentication and role-based access
- 🔍 Search and discover doctors by specialization
- 📅 Book, view, and manage appointments
- 🩺 Doctor profiles and availability management
- 📊 Dedicated patient, doctor, and admin dashboards
- 🔔 Appointment status and booking management
- 📱 Responsive user interface

### 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Version Control:** Git and GitHub

### 🎯 Project Goal
To build a user-friendly, reliable, and scalable healthcare appointment platform that simplifies the connection between patients and healthcare professionals.

**CuraNexa — Making healthcare appointments simpler, one booking at a time.**
